## 🚀 How to Run Locally

You can serve the portfolio locally using any static HTTP server or Python's built-in server:

```bash
# Using Python
python -m http.server 3000

# Or using npx serve
npx serve -p 3000
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.
