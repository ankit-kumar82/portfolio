## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/ankit-kumar82/portfolio.git
```

Open the project folder:

```bash
cd portfolio
```

Then open `index.html` directly in your browser.

For local development, you can also use the VS Code **Live Server** extension.

## ☁️ Deployment

The portfolio is deployed using **Vercel** and connected with GitHub.

Every update pushed to the main branch can be deployed automatically through the connected Vercel project.
